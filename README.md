# Redline

A personal planner web app: daily schedule, weekly routine, assignments, a don't-forget list, and week/month calendar views. Black, red and white, built to live on a phone home screen.

## Features
- Today view with a live "happening now / up next" card and free-time gaps
- Weekly routine with semester start/end dates and automatic no-class days
- Assignment tracker by class with due-date countdowns
- Don't-forget list with pins and reminders
- Auto-schedule and "plan my week" that fit tasks into free time
- Swipe right to complete, left to push to tomorrow
- Works offline, installs to the home screen

Data is stored on the device (localStorage). Use Routine → Backup & transfer to copy it out.

Built with plain HTML, CSS and JavaScript, no frameworks.
